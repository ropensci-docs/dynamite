# The dynamite Package

Easy-to-use and efficient interface for Bayesian inference of complex
panel data consisting of multiple individuals with multiple measurements
over time using dynamic multivariate panel models. Supports several
observational distributions, time-varying effects and realistic
counterfactual predictions which take into account the dynamic structure
of the model.
